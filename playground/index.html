Token thresholds

Work done in a single turn — the axis that gives turn-to-turn movement.

Percent of a 1M-token window. Only ever climbs, so it acts as a ratcheting floor.

Where the pad fades in, then reaches full.

Peak amplitude per voice. Re-synthesizes on release.
