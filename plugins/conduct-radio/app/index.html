Lo-fi for your Claude Code sessions

The more you build, the better it sounds.

It starts as a simple beat. Every token Claude writes moves the track up a level, and each level brings in more of the band: a bass line, richer chords, a melody, strings. It all stays in key.

Reads ~/.claude/projects on this machine. Nothing leaves it.
